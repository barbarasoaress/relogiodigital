# 🕒 Relógio Digital

Relógio digital desenvolvido com **HTML, CSS e JavaScript**, exibindo horas, minutos e segundos em tempo real.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Exibição de horas, minutos e segundos
- Formato de 12 horas com indicação AM/PM
- Indicadores circulares para acompanhar a passagem do tempo
- Atualização automática do horário no navegador

## 🌐 Projeto online

👉 [Acessar o Relógio Digital](https://barbarasoaress.github.io/relogiodigital/)

## 📚 Objetivo do projeto

Projeto desenvolvido durante meus estudos de desenvolvimento web para praticar manipulação do DOM, datas e horários com JavaScript e estilização com CSS.
